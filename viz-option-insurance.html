옵션모형을 이용한 포트폴리오 보험

주식 하락 위험을 옵션(또는 옵션을 흉내 낸 매매)으로 막는 4가지 전략을 차트로 비교합니다. 모든 옵션 가격은 블랙-숄즈로 계산하고, 주가는 100에서 시작해 만기는 1년입니다. ← 노트로 · CPPI 시각화 →

공통 조건

변동성이 클수록 옵션이 비싸져 보험료가 오릅니다. 슬라이더를 움직이면 모든 탭이 함께 바뀝니다.

① 방어적 풋 (Protective Put)

주식 매수 + 풋옵션 매수 (행사가 K)
방어적 풋 (합계) 주식만 풋 매수만

가로축은 만기 주가, 세로축은 손익입니다. 파란 선이 아래에서 평평해지는 지점이 보험 효과(최대손실)이고, 위로는 주식과 평행하게 오르되 풋 프리미엄만큼 아래에 있습니다.

장점

  • 구조가 단순하고, 한 번 사면 만기까지 매매가 필요 없음 (정적 전략)
  • 하락 위험이 확실하게 제한됨

한계

  • 원하는 만기·행사가격의 풋을 시장에서 구하기 어려움 (상장옵션은 만기가 짧음)
  • 프리미엄(보험료) 비용 → 상승 시 수익이 그만큼 줄어듦

② 이자추출전략

원금 100 = 채권 (만기에 보장액이 되는 만큼) + 콜옵션 매수 (남는 돈, 즉 이자 부분)
원금 100의 배분
이자추출 포트폴리오 주식 100% 보장액
핵심: 풋-콜 패리티(주식 + 풋 = 콜 + 채권)에 따라 채권 + 콜은 방어적 풋과 같은 수익구조입니다. 원금보장형 ELD·ELS가 바로 이 구조예요. 금리가 낮거나 변동성이 높을수록 콜을 살 돈이 줄거나 콜이 비싸져 참여율이 떨어집니다. 금리 슬라이더로 확인해 보세요.

장점

  • 원금(보장액)이 채권으로 확실히 확보됨
  • 최대손실 = 콜 매수에 쓴 이자 부분뿐

한계

  • 저금리일수록 남는 이자가 적어 상승 참여율이 낮음
  • 장기 콜옵션을 구하기 어려울 수 있음

③ 합성 풋 (동적헤징: 주식 + 채권)

풋옵션을 사지 않고, 주식과 채권의 비중을 계속 조정해 '주식 + 풋'을 복제
보유 주식 수 = N(d₁) (방어적 풋의 델타) → 나머지는 채권
합성 풋 (실제 매매 결과) 방어적 풋 이론가치 (목표) 주가 K의 현재가치

주식 노출 비중: 오르면 사고, 내리면 판다

왜 그런가: 델타 곡선

주가가 높을수록 풋이 쓸모없어져 '주식 + 풋'의 델타 N(d₁)이 1에 가까워집니다. 그래서 주가가 오르면 주식을 더 보유하고, 내리면 줄입니다. CPPI와 같은 추세추종입니다.

장점

  • 실제 옵션 없이도 만기·행사가격을 마음대로 정할 수 있음

한계

  • 잦은 매매 → 거래비용
  • 변동성을 추정해야 하고, 실제 변동성이 더 크면 복제 비용 증가 (횡보장 참고)
  • 연속 매매가 불가능 → 급락(갭) 시 하한이 깨질 수 있음 (1987 블랙먼데이)

④ 선물을 이용한 동적헤징

주식은 그대로 보유 + 주가지수선물 매도 비중을 조정
선물 매도 비중 = 1 − (합성 풋의 주식 노출 비중)
③과 경제적으로 같은 노출을 만듭니다. 주식을 직접 사고파는 대신 선물만 매매하므로 빠르고 거래비용이 낮습니다. 아래 차트는 베이시스가 이론가격대로 움직인다고 가정해, 가치 경로가 ③과 같습니다.
선물 매도 비중 남은 주식 노출

장점

  • 거래비용이 낮고 매매가 신속
  • 기존 주식 포트폴리오를 건드리지 않음

한계

  • 베이시스 위험: 선물이 이론가격에서 벗어나면 헤지 오차
  • 선물 만기가 짧아 롤오버 필요
  • 보유 주식과 지수의 차이(추적오차)

시험용 정리

  • 동적헤징은 급락 시에도 하한을 완벽히 보장한다 → X (갭 리스크)
