⚙️ API 키와 모델 설정
키는 이 브라우저(localStorage)에만 저장되고 각 AI 회사 서버로만 직접 전송됩니다. 이 기기를 쓰는 사람이나 악성 확장 프로그램은 볼 수 있으니 공용 컴퓨터에서는 쓰지 마세요. 유료 키(GPT, Claude)는 각 회사 콘솔에서 월 사용 한도를 꼭 정하세요. 무료 티어는 입력 내용이 모델 개선에 쓰일 수 있고, GLM은 데이터가 중국 서버에 저장됩니다. 이력서, 연락처 같은 개인정보는 넣지 마세요.

모델 이름은 각 회사 문서의 최신 이름으로 바꿀 수 있습니다. 무료 모델 목록과 한도는 자주 바뀝니다.
